## Report figures: one experimental story

These assets are **historical evidence**, generated by the final notebook's review
path. New-run metrics are written separately under the reproduction output's
`evaluation/` directory. Use PDF in the written report and PNG for previews/slides.
Each plot belongs beside the question, evidence and decision it supports.

| Figure | Question and takeaway |
|---|---|
| [01 — Method](figures/01_method.pdf) | How do raw graph/configuration inputs become the final ranking? |
| [02 — Model families](figures/02_model_families.pdf) | GraphSAGE versus matched-data HGB on shared development folds; effects differ by collection. |
| [03 — Components](figures/03_components.pdf) | Do masks/context/message passing help? Displayed standalone intervals cross zero. |
| [04 — Coverage and data](figures/04_coverage_and_data.pdf) | Do larger budgets help? Improvements are not consistent. |
| [05 — Target and objective](figures/05_target_and_objective.pdf) | Does the training objective/target matter? Keep matched within-learner controls separate from cross-learner comparisons. |
| [06 — Final results](figures/06_final_results.pdf) | How does the whole selected system compare with the basic baseline on reused audit data? |
| [S1 — Learning curves](figures/S1_learning_curves.pdf) | Supporting diagnostics: training loss and early-development tau, not two comparable losses. |

[Tables](tables/) contain source scores, controls, absolute changes and percentages
where meaningful. Read [FIGURE_CAPTIONS.md](FIGURE_CAPTIONS.md) for protocol details.
Earlier MLP results appear separately in the notebook because they use a different
protocol. There is no recovered executed gated-GraphSAGE result to plot.

The figures do not establish that every addition helped or that the system cannot
overfit. Resource-excluded configurations were not accuracy failures. Local audit
and reported public scores must remain separate. Use the narrative in
[SC4000_Final.ipynb](../../notebooks/SC4000_Final.ipynb) to connect each experiment
to its motivation and resulting decision.
