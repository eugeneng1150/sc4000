The [tables](tables/) provide the numbers behind the analysis. For a ten-page
report, select the figures that support the main argument rather than inserting
all ten. Pipeline, component ablations, target/objective comparisons and final
results are useful anchors; add coverage/data and resource plots where needed.

The learning curves do not contain validation loss and do not prove absence of
overfitting. Some component intervals cross zero. Resource-excluded experiments
are untested configurations, not failed accuracy results. Local audit metrics
must remain separate from the user-reported Kaggle score.
