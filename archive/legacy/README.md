# Earlier approaches

Historical notebooks, code, figures and report drafts live here for provenance.
They are not the final selected system. Use
[SC4000_Final.ipynb](../../notebooks/SC4000_Final.ipynb) for the final handoff.

- `SC4000_Eugene.ipynb`: earlier exploration notebook.
- `SC4000_Full_Hybrid.ipynb`, `FULL_HYBRID.md`, `CPU_GNN.md`: earlier hybrid approach.
- `gnn_final.py`: extracted earlier GraphSAGE ranker; the name is historical.
- `experiment_report.tex`, `figures/`: earlier report assets, kept together for LaTeX links.
- `test_full_hybrid.py`: checks for the matching historical hybrid notebook.

Saved outputs are retained. These notebooks may require their original data paths
and environments. Two additional local notebook snapshots are preserved under
`local/notebook_snapshots/` and excluded from Git.
